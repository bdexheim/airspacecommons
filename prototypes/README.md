# Prototypes

Clickable prototypes hosted with the site. Give each one its own folder with an `index.html`, for example:

```
prototypes/airspace-commons/index.html   the team's "Airspace Commons" page
prototypes/block-card/index.html         resident block card (R1)
```

Each prototype should carry the same "Hypothetical class project" notice as the main site. Link it from the matching board in `index.html` (section `#prototypes`).
